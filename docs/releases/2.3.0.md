# MyCLI 2.3.0

The benchmark frontend now supports repeatable run directories, explicit tool-tier selection, execution records, and visible live HTB trials. Live trials take a Linux or Windows OS, a required current target IP, and an optional box name. The operator owns machine spawn and reset. Each trial uses a private `/tmp/bench-<timestamp>` tmpfs workspace, streams the full MyCLI session to the terminal, and retains a private transcript for review. Esc interrupts a live turn and accepts operator guidance in the same session; Ctrl+C stops the trial. Task completion still requires operator verification of fresh flag reads.

In medium/full tiers, Bash now hands a command still running after 60 seconds to the existing background manager without restarting it. The model receives the task ID and partial output. A job still running at 300 seconds emits a health notice with time since output; silence alone does not imply a hang. This behavior is on by default and can be disabled with `MYCLI_BASH_AUTO_BACKGROUND=0`. The simple tier keeps its existing Bash behavior.

The live Linux and Windows briefings require background reconnaissance, point models to the installed helper catalogs and post-access enumerators, and prohibit modifying `/opt/htb-mcp`. MyCLI's Skill tool is omitted from live benchmark children so the tasks use self-contained briefings. Existing response and refusal suites remain available.

Validation: 139 MyCLI tests passed (2 ignored), 3 Cersei Bash tests passed, and 10 Python benchmark tests passed. A local tmux smoke test confirmed live permission input and Esc steering in one session. No live HTB solve was run as a release check. The local release binary reports `mycli 2.3.0`.
