# MyCLI 2.3.1

Fix `/bench` startup on Python 3.9 by deferring evaluation of type annotations in the live HTB briefing renderer. Previously, importing the renderer raised `TypeError` for the `str | None` annotation before the benchmark menu could open.

Validation: the benchmark CLI help and interactive menu opened successfully on Python 3.9.6. Eight of ten benchmark tests passed. Two existing macOS portability issues remain: the live workspace test requires Linux's `findmnt`, and the PTY test compares unresolved temporary paths with macOS's resolved paths.
