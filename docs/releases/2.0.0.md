# MyCLI 2.0.0

MyCLI 2.0.0 brings editable prompts and skills, local reasoning controls, reliable context compaction, resumable sessions, and global Markdown memory into one local-first coding and model-testing harness. It supports oMLX and DS4 alongside configured cloud providers.

This release consolidates all changes since the last published release, **1.9.5**, including the 1.9.6–1.9.8 development milestones and final 2.0.0 refinements.

## 2.0.0 — Release refinements

- **Consistent terminal colors:** Neutral text, reasoning, separators, and Markdown borders use explicit grayscale, avoiding the greenish tint from remapped terminal palettes. Cyan accents and syntax highlighting remain.
- **Correct context footer:** Context occupancy uses the latest provider-reported input count for both local and cloud models, independently of cumulative session totals. A `~` marks estimates after resume/compaction or when the provider omits usage.
- **Documentation refresh:** Updated examples and detailed guides for skills, context management, sessions, and SDK compatibility. The README retains its streamlined presentation.
- **Release packaging:** Four optimized native binaries for Linux and macOS, each bundled with configuration examples, editable prompt/skill catalogs, benchmark tools, documentation, the dependency lockfile, and build information. SHA-256 checksums accompany the downloads.

## 1.9.8 — Sessions, memory, and context management

### Resumable sessions

- Automatically persist conversations under `~/.config/mycli/sessions/<id>/` using an **append-only `transcript.jsonl` archive** and an **atomic `context.json` checkpoint**.
- Save user messages before inference, completed model replies, and tool results as work progresses. Preserve available partial response text on ordinary cancellation.
- Use `/sessions` to pick a saved session, `/sessions list` to list entries, `/sessions path` to locate its files, and `/sessions rename [id] <name>` to assign a display name without changing its ID or directory.
- Resume with `/resume <id/name/prefix>`, `/resume latest`, or `mycli --resume [id/name]`. Restore active context and reported usage, rather than replaying the entire archive into the model.
- Restore the saved project/model settings while resolving credentials and serving limits from current configuration. Configuration API keys are not copied into session metadata.
- `/quit`, `/exit`, and `/q` ask whether to keep the session. **Y/Enter keeps it; N deletes only that session folder.** Ctrl+C and EOF preserve saved sessions; single-shot runs are kept automatically.
- Use private file permissions, exclusive writer locks, atomic checkpoints, and recovery of a torn final journal entry. Interrupted tool calls are marked with an unknown outcome rather than automatically reexecuted.

### Global memory

- Add global `~/.config/mycli/MEMORY.md` and optional topic files under `memory/`, respecting `XDG_CONFIG_HOME`.
- `/memory` displays the index; `path`, `topics`, and `reload` inspect or refresh it. `/remember <fact>` explicitly appends a durable fact and applies it to the current conversation.
- Load a bounded, UTF-8-safe memory index into context. Topic files are read when relevant; automatic graph storage or fact extraction is not enabled.
- Give the model-assisted `remember` skill a concrete global destination. Deleting a session leaves global memory and the separate typed-input history intact.

### Compaction and model context windows

- Add `/compact`, `/compact <focus instructions>`, and `/compact status` for manual summarization and context-budget inspection.
- Fix automatic compaction across separate user prompts and make the configured threshold effective. Reserve output tokens and framing space before calculating the usable input budget.
- Resolve context windows from **explicit configuration → local server metadata → conservative model-family fallback**. Support additional metadata field names and prevent local aliases such as Cold-Fusion's “Fable” from matching unrelated cloud families.
- Summarize older evidence in bounded chunks, including tool-call arguments and results. Preserve recent context and complete tool-call/result rounds.
- Carry selected reasoning, thinking, and sampling settings into summarization. Count completed summary calls in session usage.
- Keep history unchanged on failed, cancelled, empty, truncated, or non-shrinking summaries. Pause automatic compaction after repeated failures; successful manual compaction resets the retry state.
- Preserve the full conversation archive when compacting active context. Fix repeated loading of persisted history and stale footer/cache-prefix accounting.
- Review upstream Cersei and adapt useful tool-pair protections without upgrading the entire SDK.

## 1.9.7 — Editable skills and direct invocation

- Add a scrolling `/skill` picker, `/skill <name> [arguments]`, `/skill list`, `/skill paths`, and `/skill reload`. Direct invocation works on every tier with that tier's existing tools.
- Share one catalog between slash commands and the model-callable `Skill` tool on the `full` tier.
- Externalize internal templates to `~/.config/mycli/skills-internal.toml`, with `MYCLI_SKILLS` override, validation, embedded defaults, and reloads that retain the previous catalog on invalid edits.
- Discover project/user skills from `.config/mycli/skills`, `.claude/commands`, `.claude/skills`, `.agents/skills`, and configured `skill_paths`.
- Fix loading when YAML names differ from directory names. Support nested commands, quoted/multiline metadata, aliases, invocation flags, argument substitution, and external skill-directory context for references.
- Improve internal workflows, including explicit Git staging and focused commit messages informed by OpenAI's skill guidance. Avoid claiming persistence or scheduling without actually performing it.
- Add bounded scrolling and label truncation so large skill catalogs fit the terminal.

## 1.9.6 — Editable prompts and local reasoning

- Externalize personas and tier guidance to `system-prompts.toml`, with `MYCLI_PROMPTS` override, embedded defaults, validation, `/prompts path`, and `/prompts reload`.
- Allow persona additions/removals without rebuilding, populate the picker from the catalog, and provide an empty `neutral` persona. Neutral suppresses persona/style text while retaining tool guidance and runtime context.
- Separate tier style from operational guidance and allow suppression by persona or model glob, including Cold-Fusion.
- Centralize configuration under `~/.config/mycli` with `XDG_CONFIG_HOME` support and legacy `.mycli` fallback. Update project configuration, history, and benchmark readers accordingly.
- Enable the local `/reasoning` picker with built-in Cold-Fusion modes: `low`, `medium`, `xhigh`, `einstein`, and `spoon`.
- Add configurable per-profile `reasoning_levels`, validation before sending requests, `/reasoning default` reset behavior, and support for the `deepseek-flash` alias. Ordinary models still require backend/template support for declared levels.
- Include an optional persona-modernization proposal and document the vendored SDK compatibility policy.

## Retained 1.9.5 baseline

These features were already in the previous published release and remain part of 2.0.0:

- **Local profiles:** `/local` and `--local` select named endpoint/model profiles with independent token limits, context windows, tool tiers, personas, and reasoning settings.
- **Sampling controls:** Configure `temperature`, `top_p`, `min_p`, and explicit model-level `thinking` for compatible local servers, including oMLX and DS4.
- **Reliable interruption:** Ctrl+C and Esc close active inference requests, including silent reasoning, response-header waits, and compaction. Supporting servers can stop generation at a safe boundary; earlier tool actions are not undone.
- **Benchmark selections:** Categories, areas, and tests start unchecked.

| Linux x86_64 | `mycli-2.0.0-linux-x86_64.tar.gz` |
| macOS Apple Silicon | `mycli-2.0.0-macos-arm64.tar.gz` |
| macOS Intel | `mycli-2.0.0-macos-x86_64.tar.gz` |

Verify archives with `SHA256SUMS`. Linux binaries are dynamically linked and built on Ubuntu 22.04. macOS binaries target macOS 13+ and are ad-hoc signed, not notarized.

Native Windows is not a supported download in this release. The current implementation needs Windows terminal handling, shell/temp-path portability, and session-filesystem validation before a Windows binary can be offered as supported.

## Upgrade notes

- Keep `mycli` alongside its bundled `bench/` directory, or set `MYCLI_BENCH` for a custom installation.
- Existing `.mycli` configuration remains readable when the corresponding new-path file is absent. Copy the bundled prompt/skill catalogs into the global configuration directory to customize them.
- Use `/local <name>` to apply a profile; `/model` selects a model directly.
- Skill templates provide instructions, not additional tools or permission grants. Advanced Claude runtime features such as hooks and forked contexts are not implemented.
- Session transcripts retain conversation content and model-visible tool results. Large raw tool-output artifacts remain subject to the existing temporary-output policy.
- Session persistence applies to sessions started with the updated binary; old input-only history cannot reconstruct earlier conversations.
